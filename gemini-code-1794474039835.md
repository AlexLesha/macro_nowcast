## Phase 2: Free Universe & Liquidity Shock Scanner
1. **`backend/app/ingestion/universe_provider.py`**:
   - Fetch S&P 500 (`https://en.wikipedia.org/wiki/List_of_S%26P_500_companies`) and S&P 400 (`List_of_S%26P_400_companies`) tables via `pandas.read_html`, mapping each ticker's GICS Sector to its SPDR ETF (`XLK`, `XLF`, `XLE`, `XLV`, `XLI`, `XLY`, `XLP`, `XLU`, `XLB`, `XLRE`, `XLC`). Cache locally in SQLite (`universe_cache` table) with a 7-day TTL.
   - Implement `get_earnings_blackout_tickers(days_buffer=3) -> set[str]` querying Nasdaq's free calendar endpoint (`https://api.nasdaq.com/api/calendar/earnings?date=YYYY-MM-DD`) across `[today - 3d, today + 4d]`.
2. **`backend/app/quant_engine/reversal_scanner.py`**:
   - Step A (Macro Gate): Call `FortyTwoMacroEngine` + `compute_bond_stress_and_accord_trigger()`. Determine `regime_throttle`:
     - `1.0` if regime in `("GOLDILOCKS", "REFLATION")` and not `bond_stress_triggered`
     - `0.5` if regime == `"INFLATION"` (filter universe to `XLE`, `XLB`, `XLI`, `XLF`, `XLV` only)
     - `0.0` (HALT) if regime == `"DEFLATION"` or `cacri > 75.0` or `bond_stress_triggered`
   - Step B (Batch Market Scan): Download 90D `auto_adjust=True` daily bars in chunks of 100 tickers (`yf.download(..., threads=True)`). Filter `Close >= 15.0`, `AvgDollarVol20D >= 50_000_000`, `ticker not in earnings_blackout`.
   - Step C (60D Rolling OLS Residual & Microstructure):
     - Regress trailing 60 daily returns $R_{i,t} = \alpha + \beta_1 R_{\text{SPY},t} + \beta_2 R_{\text{Sector},t} + \epsilon_{i,t}$.
     - Compute $\text{Residual Z-Score} = \epsilon_{i,\text{today}} / \text{std}(\epsilon_{i, -60:-1})$.
     - Compute $\text{IBS} = (\text{Close} - \text{Low}) / \max(\text{High} - \text{Low}, 10^{-6})$ and $\text{RVOL} = \text{Volume}_{\text{today}} / \text{Mean}(\text{Volume}_{-21:-1})$.
     - Select candidates where `residual_z <= -2.25`, `ibs <= 0.15`, and `rvol >= 1.8`.
   - Step D (Trade Ticket Parameters):
     - `entry_limit = round(close * 1.001, 2)` (10 bps buffer above close for next-day open/limit fill)
     - `stop_loss = round(close - 1.5 * atr_14, 2)`
     - `target_exit = round(close + 1.25 * atr_14, 2)` (or time exit at Market-on-Close T+3 trading days)
     - Rank candidates by composite `shock_score = abs(residual_z) * rvol * (1 - ibs)`.
